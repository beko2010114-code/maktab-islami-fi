# إسلامي — Final Feature Shell / No Data

هذه النسخة مخصصة للمراجعة قبل إدخال أي بيانات دينية.

المواصفات الموجودة في الهيكل:
- واجهة رئيسية.
- 12 قسمًا: القرآن، الأذكار والأدعية، الأحاديث، قصص الأنبياء، التسبيح، السيرة، أسماء الله الحسنى، الفقه، رمضان، الحج والعمرة، الزكاة، التعلم الإسلامي.
- بحث شامل.
- مفضلة.
- تقدم وإحصائيات.
- إعدادات.
- تنقل سفلي.
- تجهيز Room/SQLite وDataStore في الاعتمادات.
- تصميم عربي RTL.
- تصميم أوفلاين أولًا.
- لا أوقات صلاة ولا قبلة.
- لا توجد أي بيانات دينية تجريبية أو مولدة.

ملاحظة: هذه نسخة مراجعة للهيكل وتجربة المستخدم، وليست APK مكتمل البيانات. بعد موافقة المستخدم تُضاف البيانات التي يرسلها فقط وتُربط بالوظائف.
